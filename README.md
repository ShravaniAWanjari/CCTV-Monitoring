# GYT-CCTV

CCTV monitoring console and detection service. Repository: https://github.com/ShravaniAWanjari/CCTV-Monitoring

The code, the detection service (`backend/`) and the sample data are the same as the project had when it was copied.
How to run it, the use cases and the deployment notes are in `docs/DEPLOYMENT.md`. Start it on one PC with Docker:

    ./start.sh          # macOS / Linux   (start.cmd on Windows)

Console only, for development:

    npm install
    npm run dev
